# Конвертер конфигурации С2000-М

CLI утилита для конвертации конфигурации С2000-М в Excel таблицу со списком адресов датчиков и оборудования.

## Описание

Программа преобразует конфигурационный файл системы пожарной сигнализации С2000-М в удобочитаемую Excel таблицу, содержащую:
- Адреса устройств
- Типы приборов
- Типы шлейфов
- Назначение реле
- Описания оборудования

## Установка

```bash
pip install openpyxl
```

## Использование

### Базовый запуск

```bash
python3 main.py CONFIG_FILE [-o OUTPUT_FILE] [-v] [--check]
```

### Аргументы

- `CONFIG_FILE` — путь к файлу конфигурации С2000-М (обязательно)
- `-o OUTPUT_FILE` — выходной файл Excel (по умолчанию: output.xlsx)
- `-v` — подробный вывод информации
- `--check` — проверить и пометить отсутствующие описания

### Примеры

```bash
# Конвертация с выходным файлом
python3 main.py config.cfg -o result.xlsx

# Конвертация с подробным выводом
python3 main.py config.cfg -v

# Конвертация с проверкой отсутствующих описаний
python3 main.py config.cfg -o result.xlsx --check
```

### Вывод

```bash
python3 main.py --help
```

## Формат конфигурации

Файл должен быть в формате CSV с запятыми и пробелами как разделителями.

### Пример структуры файла:

```
Конфигурация С2000-М, Версия: 1.2, Описание: Система пожарной сигнализации
Раздел: 0, Описание: Основной раздел
Адрес: 1, Тип_прибора: 1, Тип_шлейфа: 2, Сценарий_упр: 1, Описание: Дымовой извещатель
Шлейф: 1, Описание: Пожарный шлейф первого этажа
```

### Поддерживаемые типы приборов

- Сигнал-20, Сигнал-20П
- С2000-СП1, С2000-4
- С2000-К, С2000-ИТ
- С2000-БИ/БКИ
- Рупор, Рупор-01
- И другие...

### Поддерживаемые типы шлейфов

- Охранный, Пожарный
- Тревожный, Технологический
- Входной
- Адресно-аналоговый дымовой/тепловой
- И другие...

## Модули

### cli_config.py

CLI интерфейс на основе argparse. Обрабатывает аргументы командной строки.

### config_parser.py

Класс `ConfigParser` для парсинга файлов конфигурации С2000-М.

### excel_generator.py

Класс `ExcelGenerator` для создания и настройки Excel таблиц через openpyxl.

### utils.py

Функции валидации:
- `validate_file_path()` — проверка существования файла
- `check_missing_descriptions()` — поиск отсутствующих описаний
- `format_missing_cells()` — пометка проблемных ячеек
- `validate_config_lines()` — валидация формата строк

## Особенности

### Кроссплатформенность

- **Linux:** `xdg-open` для открытия файлов
- **macOS:** `open` для открытия файлов
- **Windows:** `os.startfile()` для открытия файлов

### Обработка ошибок

- Проверка существования файла конфигурации
- Проверка кодирования (UTF-8)
- Проверка формата строк
- Подробные сообщения об ошибках

### Статистика

- Автоматическая пометка отсутствующих описаний красным цветом
- Группировка по уровням (шлейф, выход, реле)
- Настройка страницы A4 альбомная
- Разрывы страниц после 6 колонки
